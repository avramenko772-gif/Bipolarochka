# Дерево суждений (протокол дебатов)

## Узлы
- **Корень**: решение + критерий успеха (переформулировано под РФ).
- **Уровень 1 — Позиции**: по одной ветке от каждой персоны (ход + обоснование).
- **Уровень 2 — Контр-раунд**: каждая персона атакует слабейшее допущение других.
- **Уровень 3 — Обрезка**: аналитик отсекает ветки, не прошедшие критерии/guardrails.
- **Лист — Синтез**: итоговая рекомендация + план по каналам РФ.

## Критерии оценки веток (0–3 балла каждый)
1. ROI / юнит-экономика
2. Скорость до результата
3. **Риск и легальность в РФ** (маркировка, 152-ФЗ, тематические ограничения)
4. Устойчивость бренда (не выжигает репутацию)
5. Реалистичность бюджета

## Правила обрезки
- Любой red-flag из ethics-guardrails.md → ветка отклоняется независимо от баллов.
- Действие на недоступном из РФ сервисе без аналога → отклоняется.
- При равенстве баллов приоритет — устойчивость бренда и легальность.

## Выход протокола
Таблица позиций → краткое дерево аргументов → вердикт с баллами → план действий → red-flags.
