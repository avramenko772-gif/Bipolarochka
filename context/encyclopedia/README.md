# Энциклопедия российского шоу-бизнеса

Живой архив. Пополняется через Архивариуса.

## Структура

| Папка | Что хранится |
|-------|-------------|
| `персоны/` | Люди: артисты, продюсеры, менеджеры, медиа-персоны |
| `события/` | Ключевые события, скандалы, прорывы, провалы |
| `явления/` | Паттерны и механики рынка — как работает российский шоубиз |
| `связи/` | Кто с кем, почему, и что из этого вышло |

## Как добавить запись

Скажи Архивариусу: "Запиши про [X]" — он сделает остальное.

## Статус

Архив открыт. Первые записи ждут.
