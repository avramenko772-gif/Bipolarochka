# Obsidian Интеграция

Связь между агентами и Obsidian-хранилищем Таши.

## Схема работы

```
Таша говорит → Архивариус записывает MD → Google Drive → Obsidian
```

## Что попадает в Obsidian

- Записи энциклопедии (context/encyclopedia/)
- Отчёты Аудитора (ежедневные)
- Идеи от Творческого Гения (по запросу)
- Итоги дебатов Оркестратора

## Структура папок в Obsidian

```
Bipolarochka/
├── 📚 Энциклопедия/
│   ├── Персоны/
│   ├── События/
│   ├── Явления/
│   └── Связи/
├── 📋 Аудиты/
│   ├── 2026-07/
│   └── ...
├── 💡 Идеи/
└── 🎭 Дебаты/
```

- Локально на компьютере (папка)
